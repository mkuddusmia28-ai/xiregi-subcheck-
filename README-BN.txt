শিক্ষার্থী তথ্য অনুসন্ধান ওয়েবসাইট

ফাইল:
- index.html : ওয়েবসাইট
- students.xlsx : Excel ডেটা ফাইল (নিজে যোগ করতে হবে)

Excel প্রস্তুতি:
1. আপনার Excel ফাইলের প্রথম শিটে ৪ নম্বর সারিতে কলাম হেডার এবং ৫ নম্বর সারি থেকে শিক্ষার্থীর তথ্য থাকতে হবে।
2. Excel ফাইলটির নাম students.xlsx রাখুন।
3. index.html-এর সঙ্গে একই ফোল্ডারে students.xlsx রাখুন।

GitHub Pages-এ প্রকাশ:
1. GitHub-এ নতুন একটি Public repository তৈরি করুন (যেমন student-search-new)।
2. index.html এবং students.xlsx আপলোড করুন।
3. Settings > Pages > Deploy from a branch > main / root নির্বাচন করে Save করুন।
4. পরবর্তীতে নতুন Excel আপডেট করতে একই নামে students.xlsx ফাইলটি repository-তে Replace করুন।

গুরুত্বপূর্ণ:
- এই পদ্ধতিতে students.xlsx এবং ওয়েবসাইটের সব তথ্য Public হবে; লিংক জানা যে কেউ ফাইলটি ডাউনলোড করতে পারবে।
- জাতীয় পরিচয়পত্র, ফোন, ঠিকানা, জন্মতারিখ, সংবেদনশীল তথ্য বা অনুমতি ছাড়া শিক্ষার্থীর ব্যক্তিগত তথ্য প্রকাশ করবেন না।
- ওয়েবসাইটটি Excel-এর প্রথম worksheet এবং ৪ নম্বর সারির header ধরে তৈরি। ভিন্ন কাঠামোর Excel হলে কোডে পরিবর্তন লাগবে।
- Excel ফাইল আপলোড/প্রতিস্থাপন করতে GitHub-এ Admin/Write access প্রয়োজন। এটি ওয়েবসাইটের মধ্যে আলাদা লগইনযুক্ত Admin Upload প্যানেল নয়; সবচেয়ে সহজ GitHub file replacement পদ্ধতি।
